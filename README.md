# PROG5 USSD

Simulation d’un menu USSD Orange Money en TypeScript, exécuté dans un environnement Deno.
Projet inspiré des menus interactifs sur mobile _(ex: #111#)_.

## 🚀 Technologies utilisées

- **TypeScript** : Superset de JavaScript avec typage statique, idéal pour construire des projets robustes et évolutifs.

- **Deno** : Runtime sécurisé pour JavaScript et TypeScript, moderne, rapide, et conçu pour remplacer Node.js.

- **Biome** : Linter + Formatter ultra-rapide pour TypeScript, JavaScript, JSON, etc. Compatible à 97% avec Prettier.

- **pnpm** : Gestionnaire de paquets rapide et économe en espace disque, alternatif à npm/yarn.

## ⚙️ Spécifications du projet

1. **Convention de nommage** : camelCase (pour variables, fonctions, etc.)

2. **Linting** : Configuration avec Biome pour assurer la qualité du code.

3. **GitHub Actions** : Analyse statique automatique à chaque push via un workflow CI.
